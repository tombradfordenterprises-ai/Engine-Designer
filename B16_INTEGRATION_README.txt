HONDA B16 BARE-BLOCK WEBSITE INTEGRATION

Files to add/replace in your GitHub repository:

- Replace src/App.jsx
- Add public/models/b16_bare_block_dark_graphite.glb

The scene background is pure white. The model uses the darker graphite-gray block asset.
The model is currently the isolated bare-block candidate; remaining B16 component geometry
will be mapped and added as separately installable parts in a later step.

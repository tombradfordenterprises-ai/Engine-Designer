ACCESSORY DRIVE UPDATE

Adds seven individually selectable and installable components:
- Crankshaft pulley / harmonic balancer
- Water pump
- Alternator
- Power steering pump
- Belt tensioner
- Idler pulley
- Serpentine belt

Replace these three files in your GitHub repository:
- src/App.jsx
- src/components/EngineScene.jsx
- src/components/Toolbar.jsx

Commit the replacements to main. Render should auto-deploy.

Use the isometric view and orbit toward the engine's positive-X end to inspect the
front accessory-drive layout. The current procedural model is an educational
visual approximation, not manufacturer-specific CAD.

The suggested passenger-car outline is intentionally NOT included.
